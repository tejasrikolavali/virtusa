# Compliance mapping

This project mapping connects the implemented controls to relevant governance frameworks and evidence files. It is a project-oriented control summary, not legal advice.

## EU AI Act
- Human oversight: high-risk disputes are routed to human review in [src/agents/resolution.py](src/agents/resolution.py) via `human_escalation` and `recommended_action` logic.
- Transparency and traceability: OpenTelemetry spans are exported to [src/observability/tracing.py](src/observability/tracing.py) and committed to [traces/phoenix_export.jsonl](traces/phoenix_export.jsonl).
- Risk management: the decision policy is operationalized in the LangGraph workflow in [src/graph.py](src/graph.py), and the risk/state logic is described in [docs/risk-register.md](docs/risk-register.md).

## NIST AI RMF
- Govern: repository controls, audit trail, and documentation are captured in [docs/risk-register.md](docs/risk-register.md), [docs/model-card.md](docs/model-card.md), and [docs/output-risk.md](docs/output-risk.md).
- Map: the system maps dispute inputs to fraud risk and policy evidence through [src/agents/fraud_scorer.py](src/agents/fraud_scorer.py) and [src/agents/chargeback_rules.py](src/agents/chargeback_rules.py).
- Measure: execution evidence is generated by [scripts/run_all_evidence.py](scripts/run_all_evidence.py) and persisted in [reports/golden_signals.json](reports/golden_signals.json) and [reports/eval_report.json](reports/eval_report.json).
- Manage: output and input guardrails live in [src/guardrails/io.py](src/guardrails/io.py), while context isolation is enforced in [src/context/pipeline.py](src/context/pipeline.py).

## DPDP / data minimization
- Synthetic-only data is used, with customer text quarantined as DATA ONLY in [src/context/pipeline.py](src/context/pipeline.py).
- Card/account-like values are masked by sanitization in [src/guardrails/io.py](src/guardrails/io.py), and the project excludes secrets from source control via [.gitignore](.gitignore) and [.env.example](.env.example).

## Control evidence
- Guardrails: [src/guardrails/io.py](src/guardrails/io.py)
- Context isolation: [src/context/pipeline.py](src/context/pipeline.py)
- Memory persistence: [src/memory/manager.py](src/memory/manager.py)
- MCP policy access: [mcp_server/server.py](mcp_server/server.py)
- Workflow and routing: [src/graph.py](src/graph.py)
- Observability: [src/observability/tracing.py](src/observability/tracing.py)
